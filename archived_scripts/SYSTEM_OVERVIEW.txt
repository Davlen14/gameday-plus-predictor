│  ┌─────────────────────────────────────────────────────┐                  │
│  │  INGESTION PIPELINE (per coach):                    │                  │
│  │                                                      │                  │
│  │  1. Fetch metadata + headshot (CFBD API)            │                  │
│  │  2. Retrieve all games for all stints                │                  │
│  │  3. Auto-fix FBS opponent metrics (FPI/SP+)          │                  │
│  │  4. Calculate situational stats                      │                  │
│  │  5. Calculate vs coaches records                     │                  │
│  │  6. Calculate season analytics                       │                  │
│  │  7. Fetch recruiting class data                      │                  │
│  │  8. Fetch talent composite ratings                   │                  │
│  │  9. Fetch transfer portal data                       │                  │
│  │                                                      │                  │
│  │  ⏱️  Est. Time: 30-60 seconds per coach              │                  │
│  │  📡 API Calls: 7-9 per coach                         │                  │
│  │  💾 Data Inserted: 200-400 rows per coach            │                  │
│  └─────────────────────────────────────────────────────┘                  │
│                                                                             │
